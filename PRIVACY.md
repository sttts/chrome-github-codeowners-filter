# Privacy Policy

Last updated: July 30, 2026

GitHub CODEOWNERS Filter is a browser extension that filters changed files in GitHub pull requests by CODEOWNER and approver group.

## Data handling

The extension processes GitHub pull request content locally in the browser. It reads:

- file paths and ownership information displayed on GitHub pull request pages
- the repository's CODEOWNERS file from the pull request's base branch

The extension does not collect, store, sell, or transfer personal data, browsing history, repository content, or analytics to the developer or to third parties.

## Network requests

The extension communicates only with:

- `github.com`, to operate on GitHub pull request pages
- `raw.githubusercontent.com`, to retrieve the applicable CODEOWNERS file

These requests are made solely to provide the extension's user-facing filtering functionality. The extension has no developer-operated backend.

## Storage and tracking

The extension does not use analytics, advertising, tracking, cookies, or persistent extension storage.

## Changes

Material changes to this policy will be published in this repository before a corresponding extension update is released.

## Contact

Questions or concerns can be reported through the project's [GitHub issue tracker](https://github.com/sttts/chrome-github-codeowners-filter/issues).
